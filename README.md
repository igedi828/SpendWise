
# SpendWise Budget Tracker

## Project Description
SpendWise is a simple budget tracker that helps users track their income and expenses.

## Project Files

**1. index.html**
Contains the structure of the webpage, including the expense form and expenses table.

**2. style.css**
Controls the appearance of the webpage, including colors, fonts, spacing, borders, and table styling.

**3. README.md**
Provides information about the project and explains the purpose of each file.

## Technologies Used
- HTML
- CSS

## JavaScript Concepts Implemented

### 1. Variables
Used let to store the monthly budget, food expenses, transport expenses, rent expenses and remaining balance.

### 2. User Input
Used prompt() to collect budgeting information from users.

### 3. Calculations
Used addition to calculate total expenses and subtraction to calculate the remaining balance.

### 4. Functions
Created calculateTotalExpenses() and calculateRemainingBalance() to organize reusable calculations.

### 5. Output
Used console.log() to display the budget summary in the browser console.
